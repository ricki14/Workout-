# Riccardo Workout — V1

Web app personale basata sulla scheda PDF ricevuta dal PT.

## Come usarla
1. Apri `index.html` nel browser.
2. Premi **Modifica video**.
3. Incolla il link TikTok accanto all'esercizio.
4. Premi **Salva**.
5. Dalla scheda premi **🎥 Video**.

I link vengono salvati nel `localStorage` del browser, quindi questa V1 non richiede un database.
